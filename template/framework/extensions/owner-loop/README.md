# owner-loop extension

Skills and two thin workflows that let a bot or a workflow reach the person (ask and
continue, request a credential without seeing it, notify) over what Dagu 2.24.0 and
OpenMausBot 0.1.141 already provide. No service. Contract, decision (D71), evidence
and the open spikes: the framework's `docs/owner-extensions.md`.

From a generated project:

```sh
mise run ext:add ./framework/extensions/owner-loop -- --defaults
mise run doctor
```

The guide people and agents read after installing is
`extensions/owner-loop/README.md`. This file stays in the extension source.
